# Wayfinder Map: Simple Platformer Game

## Destination

A playable HTML platformer with basic mechanics: player movement (left/right + jump), collision detection, multiple levels, and a simple win condition.

## Notes

- Single HTML file architecture for simplicity (HTML5 Canvas or DOM-based)
- Use vanilla JavaScript - no frameworks
- Target: browser-only, no build step needed
- Scope: 1-2 levels, basic physics, clear win state

## Decisions so far

None yet.
