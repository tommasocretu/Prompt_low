# Prompt_low

Spazio dedicato a lavorare con LLM locali da 2/12B per un gioco HTML.

## Struttura iniziale (prima cosa da leggere)

Ogni cartella sotto è pensata per aiutare un LLM piccolo a lavorare in modo ordinato:

- `prompts/` → prompt brevi e riutilizzabili (sistema, task, correzioni).
- `contesto/` → regole di progetto e note compatte da dare in input al modello.
- `gioco/` → file del gioco HTML (pagine, script, asset).
- `valutazioni/` → test manuali, checklist e confronti tra output del modello.
- `output/` → bozze generate dal modello e risultati intermedi da revisionare.
